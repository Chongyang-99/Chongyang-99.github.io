PAD 阅读笔记

Prediction with Action: Visual Policy Learning via Joint Denoising Process — Yanjiang Guo et al., NeurIPS 2024

2026-05-31 · 原文 · PDF

摘要

PAD 是第一批把"预测未来画面"和"生成机器人动作"塞进同一个扩散过程的工作。核心想法很直觉：预测下一帧图像和生成下一步动作，本质上都需要理解物理世界的动力学规律，既然如此，为什么不让同一个模型同时做这两件事？PAD 用一个 Diffusion Transformer (DiT) 架构，把 RGB 图像、机器人姿态（甚至深度图）的未来预测统一成一个联合去噪过程。模型可以同时在机器人数据和大规模视频数据上训练，用视频里蕴含的物理常识来增强策略学习。在 Metaworld 的 50 个任务上，PAD 用一个文本条件策略实现了 72.5% 的成功率，比之前最强的 GR-1 高出 26.3%；在真实机器人上面对没见过的物体，成功率也提升了 28%。

一、Motivation

想象你在教一个机械臂抓杯子。传统 Diffusion Policy 只学"给定当前画面，该做什么动作"，它对世界的理解是隐式的，压缩在网络参数里。但如果你让模型同时预测"做完这个动作后世界会变成什么样"，它就不得不学会更深层的物理理解：杯子被推会滑多远、手指闭合后杯子会不会掉。这种预测能力不是奢侈品，是安全网。

在 PAD 之前，已经有人试过"先预测未来画面，再用另一个模型从画面反推动作"的两阶段方案（比如 SuSIE、UniPi）。但两阶段的问题是信息损失：预测画面时不知道什么信息对动作有用，结果预测了一大堆跟控制无关的像素细节，真正重要的物理特征反而被稀释了。GR-1 用自回归方式交替预测画面和动作，但自回归的误差会累积。

PAD 的切入点：既然预测和动作技术上都是扩散去噪，那就把它们真正合并成一个联合去噪过程，让同一个 attention 层同时看到图像 token 和动作 token，两边的梯度信号互相增强。

二、现存问题

  • 两阶段方案信息瓶颈：SuSIE、UniPi 先预测目标图像再推动作，预测阶段对"哪些像素对控制重要"一无所知，导致预测质量和动作质量只能分别优化，整体受限于中间表示的信息量。
  • 自回归误差累积：GR-1 逐帧预测，前一帧的误差会传播到后一帧。在长时间操作任务中，漂移会把机器人带偏。
  • 单一模态训练效率低：Diffusion Policy 只用动作做监督，大量视频数据中蕴含的物理知识完全浪费，模型容易在小规模机器人数据上过拟合。
  • 多模态扩展困难：现有框架要加一种新的输入模态（深度图、触觉），往往需要重新设计网络。

三、相关工作

Diffusion Policy

Chi et al. (2023) 把扩散模型引入机器人控制：给定观测，从高斯噪声开始逐步去噪生成动作序列。效果不错，但只有动作侧的监督信号，世界理解完全靠隐式学习。

SuSIE / UniPi：两阶段方案

SuSIE 先用一个扩散模型预测未来目标图像，再用另一个模型从（当前图像, 目标图像）推断动作。UniPi 类似但更偏向视频生成。两者的共同问题是预测和控制解耦，预测模型不知道什么信息对控制有用。

GR-1：自回归交替

GR-1 用 GPT 风格的自回归 transformer 交替生成图像和动作 token。在 Metaworld 上达到 57.4%。缺点是自回归方式下误差累积无法避免，且长序列推理慢。

PAD 与前作的关系

PAD 继承了 Diffusion Policy "用扩散做动作生成"的思路，继承了 SuSIE "用图像预测辅助策略"的目标，但用联合去噪统一了两者，避免了两阶段的信息瓶颈和自回归的误差累积。

四、方法详解

Figure 3：PAD 框架全景。当前观测编码为条件 latent，与未来帧的噪声 latent 拼接后送入 DiT 联合去噪。

4.1 整体思路

给定当前的观测（RGB 图像、机器人姿态、可选的深度图、文本指令），PAD 同时预测未来 $k$ 步的图像和动作。每一步推理后只执行第一个动作，然后重新观测、重新预测，形成闭环控制。

核心架构是一个 Diffusion Transformer (DiT)：把所有模态的 token 拼在一起，用 self-attention 让它们互相看到。图像、动作、深度图各有自己的编码器和解码器，但共享中间的 attention 层。

4.2 输入编码

  • RGB 图像：通过冻结的 VAE 编码成 latent，再切成 token 序列。
  • 机器人姿态：通过 MLP 映射到与图像 token 同维度的 token。
  • 深度图（可选）：下采样后同样 token 化。
  • 文本指令：通过冻结的 CLIP 编码器提取嵌入。

关键设计：当某种模态缺失时（比如视频数据没有动作标注），PAD 用 attention mask 把对应位置遮掉，padding token 不参与去噪计算。这样同一个模型可以灵活地在"有动作的机器人数据"和"没动作的纯视频"上混合训练。

4.3 联合去噪

条件 latent（当前帧的编码）和噪声 latent（未来帧的带噪版本）在 channel 维度上拼接。比如当前图像编码形状是 $c \times d \times d$，未来 $k$ 帧噪声 latent 形状是 $kc \times d \times d$，拼完就是 $(k+1)c \times d \times d$。然后切成 token 序列，和动作 token、深度 token 一起送进多层 DiT block。

每个 DiT block 里所有 token 做 full self-attention：图像 token 看得到动作 token，动作 token 也看得到图像 token。这是 PAD 和两阶段方法最本质的区别，信息在去噪的每一步都是双向流动的。

4.4 训练

权重初始化自 ImageNet 预训练的 DiT。训练目标是标准的 DDPM loss，同时对所有模态计算：

$$\mathcal{L}(\theta) = \lambda_I \cdot \mathcal{L}_{\text{diff}}^I + \lambda_A \cdot \mathcal{L}_{\text{diff}}^A + \lambda_E \cdot \mathcal{L}_{\text{diff}}^E$$
总训练损失 = 图像预测损失 + 动作预测损失 + 深度预测损失，各自乘一个权重系数。

其中每一项的形式：

$$\mathcal{L}_{\text{diff}}^\delta(\theta) = \mathbb{E}\left[\|\epsilon^\delta - \epsilon_\theta^\delta(z_t^\delta, t, C, l)\|_2^2\right]$$
对模态 $\delta$（图像/动作/深度），让模型预测的噪声尽可能接近真实加入的噪声，就是标准的 DDPM 训练。

训练策略上有个细节：$\lambda_I$ 始终为 1.0，而 $\lambda_A$ 和 $\lambda_E$ 从 0 线性增加到 2.0（在 100k 步内完成）。模型先专注于学好图像预测（物理理解），再逐步加入动作学习的压力。

4.5 协同训练

PAD 的协同训练分两步：先在 BridgeData-v2（60,000 条机器人轨迹）上预训练 200k 步，再在目标域适配 100k 步。由于 attention mask 的设计，预训练时也可以混入没有动作标注的纯视频数据。整个训练在 4 张 A100 上大约需要 3 天。

五、实验结果

Figure 1：PAD 在 Metaworld 和真实世界任务上的表现对比。

5.1 Metaworld 50 任务

用一个文本条件策略覆盖全部 50 个任务，每个任务只有 50 条示范轨迹。PAD-XL/2（661M 参数）达到 72.5% 平均成功率，比之前最强的 GR-1（57.4%）高了 15.1 个百分点。

5.2 真实世界泛化

在 Franka Panda 平台上测试，面对没见过的物体（草莓、胡萝卜、茄子等），PAD 达到 72% 平均成功率，加上深度模态后达到 78%。关键对比：RT-2*（69%）、SuSIE（49%）、Diffusion Policy（38%）。PAD 在"困难"级别（完全未见物体 + 多干扰）上优势更明显，baseline 几乎全部失败。

5.3 消融实验

这组实验非常清楚地回答了"图像预测到底有没有用"：

  • 去掉图像预测（PAD w/o img）：成功率从 72.5% 暴跌到 43.6%，下降 28.9 个百分点。仅靠低维姿态监督容易过拟合，图像预测提供的物理理解至关重要。
  • 去掉协同训练（PAD w/o co-train）：成功率从 72.5% 降到 59.2%，大规模视频数据的物理先验贡献了 13.3 个百分点。
  • 加入深度模态（PAD-Depth）：真实世界成功率从 72% 升到 78%，框架的多模态扩展性是实打实的。

5.4 Scaling 特性

PAD 展示了清晰的算力-性能正相关：从 PAD-B/2（128M, 62.4%）到 PAD-XL/2（661M, 72.5%），每增加计算量都能换来稳定的性能提升。值得注意的是 PAD-XL/8（661M 但 patch size 更大、Gflops 只有 7.7）只有 48.2%，关键不是参数量而是实际计算密度。

六、总结

PAD 用一个简洁的思路统一了图像预测和动作生成：既然两者都是扩散去噪，那就让它们在同一个 DiT 里共享 attention，互相增强。最重要的贡献不是数字上的提升，而是打通了一条路，机器人策略可以直接从海量互联网视频中学到物理理解，不需要每条视频都有动作标注。

局限性也很明显：联合去噪的推理速度比纯动作扩散慢（同时 denoise 图像），论文没有报控制频率；只测了三种模态，触觉等更多模态的扩展还需验证。

七、Insight

PAD 真正证明的一件事：用"预测世界"做训练信号比用"预测世界"做推理中间结果更有价值。消融实验里去掉图像预测损失暴跌 28.9 个百分点，但 PAD 推理时其实只用第一个动作，预测出的图像是扔掉的。图像预测的价值在于迫使模型在训练时建立更好的物理表征，而不在于推理时真的需要看到预测出的画面。这个发现后来被 Fast-WAM 进一步发展成"训练时想象、推理时跳过"的设计。

八、Q&A

Q1：PAD 和 Diffusion Policy 的本质区别是什么？

Diffusion Policy 只对动作做扩散去噪，观测作为条件输入。PAD 把图像和动作都当作需要去噪的目标，放在同一个 DiT 里联合处理。关键区别是动作 token 和图像 token 在 self-attention 里互相可见，动作生成会被图像预测的梯度信号影响，反之亦然。

Q2：为什么联合去噪比两阶段好？

两阶段方案的瓶颈是预测阶段不知道什么信息对动作有用，可能花大量精力还原跟控制无关的视觉细节。PAD 的联合去噪让动作侧的梯度信号回传到图像侧，引导图像预测关注对控制重要的特征。这种端到端的信息流动是两阶段方案做不到的。

Q3：loss 权重 warmup 策略为什么有效？

直接同时训练图像和动作，模型会被两个目标拉扯，容易不收敛。先让模型专注学好图像预测（建立物理理解），再逐步加入动作监督的压力，相当于先打地基再盖楼。$\lambda_A$ 最终到 2.0 意味着后期动作损失权重反而比图像高，因为最终目的还是控制。

Q4：PAD 怎么处理没有动作标注的纯视频数据？

通过 attention mask。纯视频数据只有图像，PAD 把动作和深度对应位置的 token 用 mask 屏蔽掉，不参与去噪计算。同一个模型可以混合两种数据：有标注的机器人数据贡献图像+动作损失，纯视频数据只贡献图像预测损失。

Q5：去掉图像预测后成功率暴跌说明了什么？

低维姿态监督（4-7 维）信息量太少，模型容易在小数据集上过拟合。图像预测提供了高维的、像素级的监督信号，强迫模型理解每个动作对世界的完整影响。这种理解转化为更好的内部表征，最终提升了动作预测的准确性。

Q6：PAD 能实时控制吗？

论文没有报告推理频率。PAD 推理时需要同时 denoise 图像和动作（75 步 DDIM），DiT-XL/2 有 661M 参数，在单张 GPU 上大概率低于 10Hz。后续工作 DreamZero 在类似规模下优化到 7Hz。对桌面操作任务勉强够用，但离高频控制还很远。

Q7：为什么 patch size 对性能影响这么大？

PAD-XL/8 只有 48.2%，PAD-XL/2 达到 72.5%，同样 661M 参数。patch size 越小，每张图像产生的 token 越多，self-attention 的计算量越大（Gflops 从 7.7 到 119.1），但模型能看到更细粒度的空间信息。机器人操作需要精确空间推理，细粒度 token 是必要的。
