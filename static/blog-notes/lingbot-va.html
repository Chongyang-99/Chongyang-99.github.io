摘要

LingBot-VA 是一个自回归扩散框架，把视频帧和动作 token 交错排列成一个因果序列，用 KV cache 实现高效长序列推理。建在 Wan2.2-5B 上（总参数 5.3B），用双流 Mixture-of-Transformers（视频流 3072 维，动作流 768 维）。最有意思的设计是 Noisy History Augmentation：训练时在历史帧上加噪声，让动作解码器学会从"不完美"的视频上下文中工作，推理时就可以只做半步去噪（$s=0.5$），计算量减半。在 16K 小时数据上预训练后，RoboTwin Easy 92.9%、Hard 91.6%（比 Motus 高 4-5 个百分点），LIBERO 98.5%。

方法详解

因果自回归设计

每个 token 只能 attend 到时序上在它之前的 token。视频帧和动作交错排列：$[v_0, a_0, v_1, a_1, ...]$。因果 mask 保证了物理因果性：动作 $a_t$ 只看到 $v_0...v_t$，不会"偷看"未来。

KV Cache 与持久记忆

和 LLM 一样，已处理的 token 的 key-value 缓存下来，每步只计算新 token。对长时间操作任务，缓存的历史形成"持久记忆"，减轻时间漂移。

Noisy History Augmentation

训练时对历史视频帧加噪声（模拟推理时去噪不完全的情况），动作解码器被迫学会在不完美的视觉条件下工作。推理时直接用 $s=0.5$（半步去噪），计算量减半，性能几乎不损失。

异步推理管线

动作执行和下一轮预测重叠进行，隐藏推理延迟。真实观测替换预测帧后再做后续推理（类似 DreamZero 的 KV cache 替换策略）。

实验结果

LIBERO 整体 98.5%，Object 子集 99.6%。10 条示范下 Make Breakfast 比 $\pi_{0.5}$ 高 15.6%。在记忆依赖任务（Wipe Plate、Search Box）上显著优于非因果模型。

总结

LingBot-VA 把自回归 LLM 的成功模式（因果 mask + KV cache）搬到了 WAM 领域，证明了因果设计在具身控制中的天然优势：物理因果性、高效长序列推理、持久记忆。Noisy history augmentation 是一个实用的加速 trick。

Insight

因果自回归是 WAM 的"自然语言"。物理世界本质上是因果的（现在的动作导致未来的状态），自回归模型的因果 mask 天然匹配这种因果结构。加上 KV cache 的效率优势，自回归可能是 WAM 在长时间操作任务上的最优架构选择。

Q&A

Q1：Noisy History Augmentation 的核心思路？

训练时给历史帧加噪，让模型习惯不完美的输入。推理时就可以少做几步去噪（s=0.5），计算量减半但性能不掉。本质上是 train-test 对齐的一种形式。

Q2：为什么视频流 3072 维但动作流只有 768 维？

视频需要高维表征来编码像素级信息，动作是低维信号（关节角度/位姿），768 维已经足够。非对称设计节省了大量计算。

Q3：KV Cache 替换和 DreamZero 的做法一样吗？

原理相同：用真实观测替换预测帧来消除误差累积。LingBot-VA 在自回归框架下实现更自然——直接替换 cache 中的对应 key-value。

Q4：16K 小时预训练数据包含什么？

多源异构数据：互联网视频 + 多平台机器人轨迹 + 人类操作视频。1.4 万亿 token 的预训练规模接近中型 LLM。

Q5：可变 chunk K∈[1,4] 的意义？

训练时随机选 chunk 长度，部署时可以灵活选择：K=1 最频繁纠正但计算多，K=4 计算少但纠正慢。不同任务可以选不同的 trade-off。
