摘要

UWM 是 WAM 领域里最优雅的设计之一。核心想法出奇简单：给视频和动作各自一个独立的扩散时间步（noise schedule），然后在同一个 transformer 里联合训练。推理时，只需要调节两个时间步的值，同一个模型就可以变成四种不同的东西：纯策略、纯世界模型、逆动力学模型、正向动力学模型。一个 checkpoint 四种用法，不需要改任何架构。更妙的是，这个设计让模型自然地消化没有动作标注的纯视频数据：把动作侧的时间步设为最大噪声就行了。在真实机器人实验中，UWM 比 Diffusion Policy 高出最多 20 个百分点，协同训练视频数据后泛化能力再次提升。

一、Motivation

机器人学习的数据困境：高质量示范轨迹（有动作标注的那种）收集成本极高，需要遥操作或者物理演示，一个任务几百条就算多了。但互联网上有海量的视频数据——人做家务、组装东西、操作工具——里面蕴含着丰富的物理动力学知识，只不过没有动作标注。

之前的工作要么只用标注数据（Diffusion Policy），要么需要从视频里"猜"动作标注（代价大、误差也大），要么用两阶段方案把视频和动作分开处理（PAD 的问题是时间步耦合在一起）。没有一个方案能优雅地同时利用两种数据。

UWM 的切入点：既然扩散模型的核心是"在不同噪声水平之间穿梭"，那为什么不给每种模态一个独立的噪声水平控制？这样，当某种模态缺失时，只需要把它的噪声设到最大（相当于"我对这个模态一无所知"），模型自然就退化成只处理剩余模态的版本。

二、现存问题

  • 标注数据稀缺：高质量机器人示范需要遥操作采集，每条成本以分钟计。100 条轨迹可能就要大半天，1000 条需要数周。
  • 视频数据有物理知识但无动作：YouTube 上有无穷无尽的操作视频，但只有像素，没有机器人的关节角度和末端执行器位姿。
  • PAD 的耦合时间步：PAD 给所有模态用同一个扩散时间步，这意味着训练时图像和动作的噪声水平是绑定的，无法灵活地"只去噪动作、忽略图像"。
  • 策略和世界模型割裂：传统方案里，策略（给定观测预测动作）和世界模型（给定观测和动作预测下一帧）是两个独立的模型，不共享知识。

三、相关工作

Diffusion Policy

Chi et al. 的扩散策略用 DDPM 从噪声生成动作 chunk，在行为克隆上效果很好。但它只有动作侧的监督，不做世界预测，无法利用无标注视频数据。

PAD

PAD 把图像和动作放在同一个 DiT 里联合去噪，证明了图像预测能大幅提升策略性能。但 PAD 给所有模态共用一个时间步，无法灵活切换推理模式，也不能优雅地处理缺失模态。

GR-1

GR-1 用自回归 transformer 交替预测图像和动作，但确定性回归（MSE loss）无法建模多峰分布，且自回归误差累积。

四、方法详解

Figure 2：UWM 训练与推理流程。左：联合训练，中间用 mask 吸收无动作视频。中/右：调节时间步切换推理模式。

4.1 核心设计：独立时间步

UWM 的噪声预测网络写成：

$$s_\theta(o,\; a_{t_a},\; o'_{t_{o'}},\; t_a,\; t_{o'})$$
网络同时接收当前观测 $o$、带噪的动作 $a_{t_a}$、带噪的下一帧 $o'_{t_{o'}}$，以及各自独立的时间步 $t_a$ 和 $t_{o'}$。

关键在于 $t_a$ 和 $t_{o'}$ 是独立采样的。训练时，模型见过所有可能的 $(t_a, t_{o'})$ 组合。推理时：

  • 策略模式：设 $t_{o'} = T$（下一帧全噪声，意为"我不关心预测画面"），只对动作去噪。
  • 视频预测模式：设 $t_a = T$（动作全噪声，意为"我不知道动作是什么"），只对下一帧去噪。
  • 正向动力学：设 $t_a = 0$（动作已知），对下一帧去噪——给定"做了什么"，预测"世界变成什么样"。
  • 逆动力学：设 $t_{o'} = 0$（下一帧已知），对动作去噪——给定"世界变成了什么样"，反推"做了什么"。

4.2 训练目标

$$\ell(\theta) = \mathbb{E}\left[w_a \|\epsilon_a^\theta - \epsilon_a\|_2^2 + w_{o'} \|\epsilon_{o'}^\theta - \epsilon_{o'}\|_2^2\right]$$
标准扩散损失，但分别对动作和观测计算，权重 $w_a$ 和 $w_{o'}$ 控制两边的比重。训练时 $t_a$ 和 $t_{o'}$ 从均匀分布独立采样。

4.3 消化无标注视频

对于没有动作标注的视频数据，直接设 $t_a = T$，把动作换成纯噪声 $\epsilon_a \sim \mathcal{N}(0, I)$。此时训练 loss 自然退化成只有观测侧的项。模型学到的是"世界怎么变化"的规律，不需要知道"是什么动作导致了变化"。

4.4 架构细节

  • 图像编码：每帧通过 SDXL VAE 压成 28x28x4 latent，再 patch 化成 transformer token。
  • 动作编码：每步动作通过浅层 MLP 映射成 token。
  • Register token：额外加了一组随机初始化的 token（推理时丢弃），促进跨模态信息交换。作者发现这对性能有帮助。
  • 时间步注入：$t_a$ 和 $t_{o'}$ 通过正弦编码 + AdaLN 注入 transformer。

五、实验结果

5.1 真实机器人

在 DROID 数据集上预训练（2000 条轨迹），再微调到 5 个真实世界任务。UWM 在分布内（ID）和分布外（OOD）都显著领先。

协同训练（UWM-Co，加入 2000 条无标注视频）在所有 OOD 场景下都比只用标注数据的 UWM-Pre 更好，提升幅度 4-12 个百分点。Diffusion Policy 在 OOD 下掉得最厉害，PAD 在多数任务上接近 0。

5.2 LIBERO 仿真

在 LIBERO-100 的 90 个环境上预训练，10 个 OOD 环境上测试。UWM 平均成功率 79%，比 Diffusion Policy（71%）、PAD（57%）、GR-1（58%）都高。仿真场景下提升幅度比真实世界小，可能因为仿真动力学更简单。

5.3 关键消融

  • 从头训练 vs 预训练：不做预训练时，UWM 和 DP 性能相当。预训练后 UWM 拉开差距，说明统一架构在利用大规模数据时优势更大。
  • Register token：去掉 register token 性能下降，说明跨模态信息交换需要额外的"缓冲区"。
  • 逆动力学模式：在轨迹跟踪任务上，逆动力学模式比策略模式更准（65% vs 47%），说明模型确实学到了不同模式的不同能力。

六、总结

UWM 用一个极简的设计（独立时间步）统一了策略学习和世界建模。最重要的贡献是证明了：同一个模型可以同时作为策略、世界模型、逆动力学模型使用，且四种模式之间的知识是共享增强的。协同训练无标注视频数据的能力让 UWM 在数据利用效率上远超只用标注数据的方法。

不足：仿真场景下提升幅度有限；大规模预训练的算力成本没有详细报告；视频协同训练对视频质量和多样性的敏感度还没有深入探索。

七、Insight

独立时间步是 WAM 的通用接口设计。UWM 证明了一件事：在扩散模型里，"缺失模态"和"设时间步为 T"是等价的。这不是工程 trick，是一个关于扩散模型表达能力的深层洞察。一旦接受了这个观点，模型设计的自由度就打开了：你可以把任意数量的模态塞进同一个扩散过程，只需要给每个模态一个独立的时间步控制。这个设计模式后来被 DreamZero、Cosmos Policy 等后续工作广泛采用。

八、Q&A

Q1：UWM 和 PAD 最核心的区别是什么？

时间步是否独立。PAD 给所有模态共用同一个扩散时间步 $t$，训练时图像和动作的噪声水平永远相同。UWM 给每个模态独立的时间步 $t_a$ 和 $t_{o'}$，训练时随机采样所有组合。这个看似微小的改动带来了本质区别：UWM 可以在推理时灵活切换模式，PAD 做不到。

Q2：为什么设 $t_{o'} = T$ 就等于纯策略？

$t_{o'} = T$ 意味着下一帧观测完全被噪声覆盖，对模型来说等价于"我对未来画面一无所知"。此时模型只能依赖当前观测 $o$ 来去噪动作。训练时模型见过了 $t_{o'} = T$ 的情况，所以推理时直接用这个设定就能得到纯策略输出。本质上是利用了扩散模型"噪声最大 = 无信息"这个对应关系。

Q3：协同训练视频数据为什么能提升 OOD 泛化？

视频数据包含了各种环境变化（不同光照、背景、物体外观），模型通过预测这些变化学到了更鲁棒的视觉表征。当测试时遇到新的视觉干扰，这种表征比只在标注数据上学到的更耐用。从数据量角度看，2000 条额外视频就能带来 4-12 个百分点的 OOD 提升，性价比极高。

Q4：Register token 的作用是什么？

Register token 是一组额外的 learnable token，在 self-attention 中参与计算但推理时丢弃。作者认为它充当了跨模态信息交换的"缓冲区"：动作 token 和图像 token 维度差异很大，register token 为两者的特征融合提供了中间地带。这和 ViT 中 register token 消除 attention sink 的作用类似。

Q5：为什么 PAD 在 UWM 的实验里表现很差（接近 0）？

UWM 论文指出，PAD 使用原始像素级的 channel-wise 拼接来做条件注入，而不是特征编码。在 UWM 的实验设置下（更复杂的真实场景），这种粗暴的像素拼接让模型难以学到有效的条件关系。这也说明条件注入方式对性能影响巨大。

Q6：UWM 的四种推理模式真的都有用吗？

策略模式是核心用途。逆动力学模式在轨迹跟踪上比策略更准（65% vs 47%），证明它学到了不同的能力。世界模型模式可以用于 planning 或数据增强。正向动力学用于"如果我做这个动作会怎样"的预判。四种模式不是噱头，每种都有明确的应用场景。但论文主要展示了策略模式和逆动力学模式的定量结果，世界模型和正向动力学主要是定性展示。

Q7：UWM 的推理速度如何？

论文没有直接报告推理频率。架构上 UWM 在策略模式下只需要对动作去噪（$t_{o'} = T$ 意味着不需要预测图像），所以理论上比 PAD 快——PAD 必须同时 denoise 图像和动作。但 UWM 仍然是迭代扩散采样，不是一步出结果的。
