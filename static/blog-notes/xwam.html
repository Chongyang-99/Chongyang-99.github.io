X-WAM 阅读笔记

Unified 4D World Action Modeling from Video Priors with Asynchronous Denoising — Jun Guo et al., 2026

2026-05-31 · 原文 · PDF

摘要

X-WAM 做了一件之前没人做过的事：把 WAM 从 2D 像素预测扩展到 4D（多视角 RGB-D），在一个模型里同时生成多视角视频、深度图、本体感知和动作。这不是简单地加一个深度预测头——X-WAM 设计了一个轻量的深度分支（复制 DiT 最后几层，用单向交叉注意力读取主分支特征），不增加动作推理延迟。另一个关键创新是异步噪声采样（ANS）：训练时的噪声分布被精心设计来匹配异步推理的场景（动作先出，视频慢慢 denoise），解决了之前解耦训练+异步推理时的 train-test mismatch。在 5800+ 小时数据上训练后，RoboCasa 79.2%、RoboTwin 2.0 90.7%，都是 SOTA。4D 重建质量也远超现有方法（Chamfer Distance 0.0049 vs DreamZero+DA3 的 0.0680）。

一、Motivation

之前的 WAM（PAD、UWM、DreamZero、Cosmos Policy）都在 2D 像素空间工作：预测未来的 RGB 图像。但机器人操作本质上是 3D 的：你需要知道物体离手多远、桌子有多高、障碍物在哪。2D 像素预测对深度信息的理解是隐式的、不可靠的。

X-WAM 的思路：让 WAM 不只预测未来的"画面"，还预测未来的"空间"（深度图）。多视角 RGB + 深度 = 完整的 4D 感知。挑战是深度预测会大幅增加计算量（token 数翻倍），X-WAM 用一个巧妙的分支架构来避免这个问题。

二、方法详解

2.1 架构

基于 Wan2.2-5B DiT，输入是语言指令 + 初始状态 + 多视角 RGB 图像，输出是未来 8 帧 RGB 视频 + 深度 + 32 步动作。所有模态 token 拼接后用双向 attention 处理。

2.2 轻量深度分支

不是把深度 token 和 RGB token 简单拼接（会让序列长度翻倍、attention 成本翻四倍），也不是在 channel 维度融合（会破坏预训练的分布）。X-WAM 复制了 DiT 最后 M 层做深度专用分支，通过单向交叉注意力从主分支读取特征，但主分支完全不受深度分支影响。

效果：深度预测不增加动作推理的延迟（1033ms 不变），同时深度质量很好（AbsRel 0.0349）。

2.3 异步噪声采样（ANS）

推理时想要动作快速出来（5 步去噪），视频可以慢慢生成（25 步去噪）。但如果训练时用独立采样的时间步（UWM 风格），模型在推理时会遇到训练时没见过的配置（$t_a = 0$ 但 $t_O$ 还很大）。

ANS 的解决方案：训练时用联合分布采样，让 $t_a$ 和 $t_O$ 之间有相关性——当 $t_a$ 较小时，$t_O$ 倾向于比 $t_a$ 大但不会太大。这样训练分布覆盖了异步推理的所有可能场景。

$$t_O = t_a + (1 - t_a) \cdot b, \quad b \sim \text{Beta}(1.5, 1)$$
视频时间步 $t_O$ 总是 $\geq t_a$（视频比动作更noisy），偏移量由 Beta 分布控制。训练时覆盖了 $t_a=0, t_O>0$ 的情况。

2.4 训练

Flow matching 框架，总损失：

$$\mathcal{L}_{\text{total}} = \mathcal{L}_O + \lambda_s \mathcal{L}_s + \lambda_a \mathcal{L}_a + \lambda_D \mathcal{L}_{\text{depth}}$$
RGB 视频 + 状态 + 动作的 flow matching 损失，加上深度的 MSE 损失。

在 5800+ 小时数据上训练（真实 + 仿真混合），统一接口：双臂末端执行器位姿 + 夹爪。

三、实验结果

RoboTwin 2.0（50 个双臂任务）：X-WAM 在 Randomized 设置下 90.7%，比 Motus（87.0%）高 3.7 个百分点。

4D 重建质量：PSNR 23.46（vs DreamZero+DA3 的 21.12），Chamfer Distance 0.0049（vs 0.0680），深度质量提升了一个数量级。

关键消融

  • 深度分支：去掉深度后成功率从 67.8% 降到 63.0%，深度信息对策略有实质帮助。
  • ANS vs 解耦：解耦训练+异步推理 67.2%，PSNR 22.60；ANS 训练+异步推理 67.8%，PSNR 23.46。ANS 修复了 train-test mismatch。
  • 深度架构选择：序列拼接延迟翻倍（1888ms vs 1033ms），channel 拼接成功率掉到 64.2%，交错分支是唯一兼顾速度和质量的方案。

四、总结

X-WAM 把 WAM 从 2D 推向 4D，加入显式的空间理解。两个核心贡献：轻量深度分支（零延迟增加）和 ANS（train-test 一致的异步推理）。在策略性能和 4D 重建质量上都达到 SOTA。

局限：只在仿真和有限真实场景测试；5800 小时数据的需求量依然很大。

五、Insight

异步推理不是工程 trick，它需要专门的训练策略。X-WAM 最重要的发现是：解耦时间步训练 + 异步推理存在 train-test mismatch（PSNR 从 23.48 掉到 22.60）。ANS 通过让训练时的噪声分布"预见"推理时的异步场景来修复这个问题。这个洞察对所有需要不同模态以不同速度推理的 WAM 都有价值。

六、Q&A

Q1：深度信息为什么能提升策略性能？

从 63.0% 到 67.8%，+4.8 个百分点。深度提供了显式的 3D 空间理解：物体离手多远、桌面高度、障碍物位置。纯 RGB 的世界模型只能隐式推断这些信息。在精确操作任务（如放入容器、堆叠）中，毫米级的深度精度是关键差异。

Q2：单向交叉注意力为什么比双向好？

主分支保持预训练权重不变（不被深度梯度影响），深度分支通过读取主分支特征来学习。如果用双向注意力，深度分支的梯度会回流到主分支，可能破坏预训练学到的 RGB 时空表征。这也是为什么 channel 拼接效果差——它直接改变了主分支的输入分布。

Q3：ANS 的 Beta(1.5,1) 分布怎么理解？

Beta(1.5,1) 的均值是 0.6，意味着 $t_O$ 大概率比 $t_a$ 大 60% 的剩余空间。直觉上：视频总是比动作更noisy（因为推理时动作先 decode 完），训练时就让模型适应这种"动作快、视频慢"的配置。如果用均匀分布，模型会花一半时间学 $t_O < t_a$ 的情况，但推理时永远不会遇到。

Q4：X-WAM vs Cosmos Policy 谁更强？

RoboCasa 上 X-WAM 79.2% vs Cosmos Policy 67.1%，差距很大。但两者不完全可比：X-WAM 用了 5800 小时数据，Cosmos Policy 用 50 条示范。X-WAM 的优势来自显式 3D 理解和大规模数据，Cosmos Policy 的优势在数据效率和 planning。在不同的数据预算下，两者的排名可能反转。
