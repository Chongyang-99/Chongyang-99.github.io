BFM 演进脉络

从 DeepMimic 到 SONIC — 人形机器人行为基础模型的技术演进与横向对比

2026-06-05 · 覆盖 DeepMimic, AMP/ASE/CALM, HOVER/ASAP, FB-CPR, BFM-Zero, BeyondMimic, Humanoid-GPT, SONIC · Survey

总览

2018 年，DeepMimic 确立了用强化学习跟踪动捕数据的基本范式。此后八年间，人形全身控制经历了五次范式跃迁，从"每个动作训一个专用策略"走到了"所有动作共享一个 token 空间"。这篇笔记沿着这条主线，横向对比四个当代 BFM 方案（BeyondMimic、BFM-Zero、SONIC、Humanoid-GPT），梳理它们之间的继承与分歧，并提炼出贯穿始终的五大趋势。

如果只用一句话概括：人形控制正在重走自然语言处理的 scaling 之路。2025 年下半年，BFM-Zero 证明无监督也能训出通用策略，BeyondMimic 证明扩散模型能做测试时组合。2026 年，Humanoid-GPT 证明 Transformer 架构在这个领域同样具备 scaling 优势，SONIC 则沿着密集监督、离散 token 和三轴 scaling 这条独立路径，走出了目前综合最完整的通用控制基座。四条路线各自独立演化，却共同指向了同一个方向。

核心性能指标

四个关键维度深入对比

1. 训练范式：一阶段 vs 两阶段

BFM-Zero 和 SONIC 都选择了一阶段端到端训练。前者用 off-policy TD3 同时学习策略和 FB 表示，跳过了蒸馏环节；后者用 PPO + FSQ 联合优化，梯度通过 straight-through estimator 直接回传编码器，训练过程中不存在信息瓶颈。

BeyondMimic 和 Humanoid-GPT 则沿用了两阶段路线：先训练一批底层跟踪策略，再将它们蒸馏到统一空间。BeyondMimic 蒸馏到 VAE + 扩散模型，Humanoid-GPT 用 DAgger 蒸馏到因果 Transformer。问题在于，两阶段方案的最终质量始终受制于底层策略：底层学不好的动作，蒸馏也救不回来。

趋势已经相当明确：一阶段端到端方案正在取代两阶段蒸馏。

2. 统一表示：连续 vs 离散

BFM-Zero 的 z 向量是 256 维连续空间，背后有线性奖励最优性定理作数学保证：对于任何可写成 $r(s) = \phi(s)^\top z$ 的奖励函数，策略 $\pi_z$ 自动就是最优策略。理论上非常优雅，但连续空间对 VLA 的下游预测并不友好。

SONIC 走了相反的路，把所有运动压缩到 64 维离散 FSQ token 空间。VLA 消融实验给出了直接的定量对比：离散 token 的任务成功率比连续 SMPL 姿态空间高出 42 个百分点（68% vs 27%），逻辑和自然语言建模选择离散 token 而非连续 embedding 一脉相承。

BeyondMimic 的策略是在 VAE 连续隐空间上叠加扩散模型，优势在于天然适合多模态建模和技能组合，代价则是推理时需要 8 步去噪迭代，实时性受到制约。

总的趋势是：离散 token 化正在成为主流选择。

3. Scaling 特性

4. 任务泛化机制

BFM-Zero 的泛化最为直接：换一个 z 向量就等于切换到一个新任务。奖励优化场景用 $z_r = \frac{1}{N}\sum_i r(s_i)B(s_i)$，目标到达用 $z_g = B(s_g)$，动作跟踪用 $z_\tau = \sum B(s_t)$。但它只能处理可以表示为状态特征线性组合的奖励函数，这限制了适用范围。

SONIC 通过模块化实现泛化：换一种输入模态只需切换对应的 encoder（robot / human / hybrid），底层的 control decoder 完全不动。VLA 更是跳过 encoder，直接预测 64 维 token。这让新模态的接入成本降到最低。

BeyondMimic 的泛化发生在推理时：扩散模型生成动作的过程中，classifier guidance 将任务目标函数（速度向量、避障势场等）的梯度注入去噪过程，不重训就能组合出新技能。这是四个方案中最灵活的，但也是最慢的。

Humanoid-GPT 则走最简洁的路线，什么都不换，纯靠 Transformer 的上下文建模能力泛化到训练时没见过的动作。代价是它目前只做 tracking 一件事。

阶段一：单任务手工调参（2018-2020）

2018 · DeepMimic (Peng et al.)
开创用 RL 跟踪动捕数据的范式。每个动作一个策略，奖励函数手工设计。

DeepMimic 确立了一套清晰的工作流：拿到一段动捕片段，为它设计跟踪误差奖励，在 MuJoCo 里用 PPO 训练一个三层 MLP 策略，不断迭代直到策略能稳定复现目标动作。在这套流程下，单个动作的还原质量可以做得非常高。

然而，这里藏着一个根本性的扩展瓶颈：每新增一个动作，所需的人力投入几乎等同于从零开始。每段动捕都要重新调奖励权重、终止条件和域随机化参数，想覆盖几百种动作，人力成本就线性增长。质量和规模之间形成了不可调和的矛盾。

这个阶段很像 NLP 的"规则模板"时代：手工打磨的单条规则可以很精准，但系统的能力完全无法随数据增长而自动提升。

阶段二：对抗式风格学习（2021-2023）

2021-2023 · AMP → ASE → CALM (Peng et al.)
GAN 判别器做风格奖励，省去手工 reward。ASE 加 skill embedding，CALM 加可组合 latent。

这一代的核心创新是用 GAN 判别器取代手工奖励。AMP 从动捕数据里采"专家"状态转移、从策略里采"生成"状态转移，让判别器区分真假，再把判别器的输出当作奖励信号。策略由此从"追踪具体帧"转变为"学习动作风格"，一下子摆脱了逐帧调参的负担。

在 AMP 的基础上，ASE 引入了 skill embedding 向量，让一个策略能覆盖多种技能。每种技能对应潜空间中的一个区域，切换技能就是切换 embedding。CALM 则更进一步，加入可组合的 latent 条件和条件判别器，实现了有条件的风格控制。

然而，对抗训练有一个绕不过去的 根本性弱点：当动捕数据从几种动作扩展到数千种时，真实分布变成极高维的多模态混合体，判别器越来越难以有效区分真假，训练信号逐渐退化为噪声。策略失去可靠的梯度方向后，倾向于 mode collapse，最终只学会少数"安全"的动作模式。回顾来看，这其实和文本生成领域 GAN 败给自回归模型的原因如出一辙：密集监督信号的信息量能随数据线性增长，而对抗信号不能。

阶段三：两阶段蒸馏与多任务整合（2024-2025 上半）

2024-2025H1 · HOVER / ASAP / OmniH2O (He et al., CMU)
先用 PPO 训练多个跟踪策略，再用 CVAE 蒸馏到共享潜空间。首次上真机。

这一代的思路很务实：既然 PPO tracking 本身已经能做出不错的单动作策略，那就先把这一步做扎实，再想办法把多个专家的能力"融合"到一个统一模型里。

  • HOVER 为多段动捕分别训练 PPO 跟踪策略，再用 CVAE 蒸馏到统一的潜空间，从而实现多任务之间的平滑切换。
  • ASAP 换了个角度弥补 sim-to-real 的鸿沟：先在仿真中训练跟踪策略，再到真机上采集数据训练一个残差模型来补偿动力学偏差。
  • OmniH2O 则走层级路线，上层接收 VR 输入做运动规划，下层跟踪器负责执行。

这一代的历史性贡献在于 首次把多技能人形全身控制搬上了真实硬件。但与此同时，核心瓶颈也暴露得很充分：

  • 蒸馏天花板：统一潜空间的质量被底层单策略的质量严格限制。如果某些动作的 PPO tracker 训练不充分，蒸馏出来的潜空间就会出现"空洞"，那些动作就永远做不好。
  • On-policy 的低数据效率：PPO 每一步环境交互只用一次就丢弃，面对大规模多动作数据集时训练代价高昂。
  • 两阶段流水线的工程复杂度：每个阶段有各自的超参数和不稳定性，联合调试成本远超单阶段方案。

阶段四：多范式并行突破（2025 下半）

2025 年下半年出现了一个引人注目的现象：两条方法论截然不同的技术路线几乎同时宣布突破，却不约而同地指向同一个目标：可 scale 的通用全身控制基座。

路线 A：隐空间扩散（BeyondMimic）

2025-11 · BeyondMimic (Liao et al., UC Berkeley & Stanford)
精炼 RL tracking + VAE + 扩散模型。Classifier guidance 在线组合技能。

BeyondMimic 把赌注押在了两件事上：把单个动作做到极致自然，以及 让模型在测试时能灵活组合已有技能。

  • 单动作质量最高：空翻时骨盆角速度峰值 20 rad/s，和人类体操运动员一个量级。用户研究 70.8% 的人觉得它的走路跑步比宇树官方控制器更像人。
  • Classifier guidance 组合技能：推理时注入任务目标函数做梯度引导，不重训就能完成避障、导航、摇杆遥操、运动补帧等从没训过的任务。
  • "少即是多"的 DR 哲学：故意只随机三个参数。更少的随机化让策略专注于学动作本身。

代价是推理慢（8 步扩散去噪，~25Hz），实时性受限。

路线 B：无监督 RL（BFM-Zero）

2025-11 · BFM-Zero (Li et al., CMU & Meta)
Off-policy 无监督 RL + Forward-Backward 表示学习。首次从仿真走上真机的无监督 BFM。

BFM-Zero 另辟蹊径：既然为每个任务标注奖励是瓶颈，那干脆不标注。让 off-policy RL 在仿真里自由探索，动捕数据只通过 GAN 判别器提供"像人"的风格约束，整个训练过程不依赖任何任务奖励。训练结束后，Forward-Backward 表示学习自然地产出一个结构化的潜在任务空间，其中每个 z 向量对应一个具体任务和对应的最优策略。

它带来了几个关键突破：

  • 一阶段端到端：跳过蒸馏，off-policy TD3 同时学策略和表示
  • 可提示：换 z 向量 = 换任务，和 LLM 的 prompt 概念异曲同工
  • Prompt-level adaptation：不改参数只优化 z 就能适应 4kg 负载变化
  • 鲁棒性是"免费的"：抗扰恢复不是靠推力扰动训练出来的，而是 off-policy 探索的自然结果

阶段五：Scaling 驱动的统一（2026）

2026 年，SONIC 和 Humanoid-GPT 几乎同期发表，从不同角度将 scaling 推到了新高度。

SONIC：密集监督 + 离散 token + 三轴 Scaling

2026 · SONIC (Luo et al., NVIDIA)
Motion tracking 当基础任务。1 亿帧 + 42M 参数 + 21K GPU-hr。FSQ universal token 统一五种模态。

SONIC 选择了一条看似朴素但极其 scalable 的路：把 motion tracking 当成基础训练任务，逐帧动捕数据提供密集监督，不需要手工奖励也不需要对抗训练。在此基础上：

  • 它用 FSQ 离散 token 取代了连续潜空间，直接解决了连续表示对 VLA 不友好的问题
  • 它在数据（1 亿帧）、模型（42M 参数）和算力（21K GPU-hr）三个维度上同时 scaling，且没有一条曲线出现饱和
  • Universal token 将 VR、视频、文本、音乐和 VLA 五种输入模态统一到同一个控制策略中
  • GR00T N1.5 直接预测 token 驱动真机完成 loco-manipulation，五项任务平均成功率 75%

Humanoid-GPT：专家蒸馏 + Transformer Scaling

CVPR 2026 · Humanoid-GPT (Qi et al., Tsinghua)
300 个 PPO 专家 + DAgger 蒸馏到因果 Transformer。首次证明 Transformer > MLP 在人形 tracking 上的 scaling 优势。

Humanoid-GPT 的策略不是推翻现有范式，而是把它推到极限，看看 scaling 的天花板究竟在哪里。

  • HME 聚类：用 periodic autoencoder 抽取运动的振幅/频率特征，把 20 亿帧数据聚成 300 个语义簇
  • 分簇训练：每个簇一个 PPO 专家，算力友好
  • GPT 蒸馏：用 DAgger 把 300 个专家蒸馏到一个因果 Transformer
  • 关键发现：同参数量的 MLP 在大数据上饱和，Transformer 还在稳步进步。80M 参数做到 <1.5ms 推理延迟，打破了"Transformer 太重不能做实时控制"的偏见。在 tracking 精度（MPJPE-L 22.5mm）上甚至略优于 SONIC（23.2mm）。

两者的关系

SONIC 和 Humanoid-GPT 各有所长：SONIC 的模态覆盖最广，是唯一完成 VLA 对接的方案，tracking 成功率更高（98.7% vs 94.4%）；Humanoid-GPT 在关节精度上略占优势（MPJPE-L 22.5mm vs 23.2mm），并且给出了 Transformer 架构在 humanoid tracking 上 scaling 不饱和的关键实证。一个自然的猜想是：把 SONIC 的 FSQ token + 多编码器设计和 Humanoid-GPT 的 Transformer backbone 组合起来，可能释放更大的潜力。

Motion tracking + dense supervision + discrete token = 人形控制的 "next token prediction"。找到一个可 scale 的基础训练任务，让数据、模型和算力三者同时推大，性能就能一路上升。这正是大语言模型过去五年走过的路。

论文详读

以下按时间顺序，对四篇核心工作做简要提炼。每篇附有完整阅读笔记的链接。

BeyondMimic UC Berkeley & Stanford · 2025-11

一句话：精炼 RL 配方做大规模运动跟踪，再用隐空间扩散模型 + classifier guidance 实现测试时零样本技能组合。

BeyondMimic 分两步走。第一步用一套统一的 RL 超参训练机器人跟踪各种人类动作（空翻、旋风踢、冲刺跑），同一套配方直接迁移到真机，不用逐动作调参。第二步把这些"原子技能"用 VAE + 扩散模型整合到一个隐空间里，推理时通过 classifier guidance 注入任务目标函数做梯度引导，不重训就能组合出避障、导航、摇杆遥操等从没训练过的任务。

关键结果：用户研究 70.8% 的人觉得它的步态比宇树官方控制器更像人；空翻时骨盆角速度峰值 20 rad/s，和人类体操运动员一个量级；所有技能零样本迁移到 Unitree G1。代价是扩散推理需要 8 步去噪，实时性约 25Hz。

核心 Insight：扩散模型做控制的正确姿势是联合建模状态和动作，而非只建模动作。VAE 不是可选项而是必要组件，原始动作空间太不规则（5% vs 95% 成功率）。域随机化"少即是多"，故意只随机三个参数反而让策略更专注于学动作本身。

BFM-Zero CMU & Meta · 2025-11

一句话：Off-policy 无监督 RL + Forward-Backward 表示学习，训出第一个能上真机的可提示行为基础模型。

BFM-Zero 不给任何任务奖励，让 off-policy RL（TD3）在仿真里自由探索，动捕数据只通过 GAN 判别器提供"动作要像人"的风格约束。训练结束后，FB 表示学习自动得到一个结构化的潜在任务空间：每个 z 向量对应一个任务和该任务下的最优策略。部署时换 z 就换任务（奖励优化用 $z_r$，目标到达用 $z_g$，动作跟踪用 $z_\tau$），完全不改模型参数。

关键结果：Unitree G1 上零样本完成跟踪、目标到达、奖励优化；给机器人加 4kg 负载后只在 z 空间做 20 轮 CEM 优化就能恢复单腿站立；抗扰恢复不是靠推力扰动训练出来的，而是 off-policy 探索的自然结果。Booster T1 上用同一套超参也训练成功，展示了跨形态潜力。

核心 Insight：Off-policy 训练不只是数据效率高，更关键的是 FB 表示学习天然需要 off-policy 数据来估计长期状态访问分布，这解释了为什么以前没人用 on-policy 走通这条路。z 向量不只是条件信号，它定义了一个可解释、可插值的技能空间。

SONIC NVIDIA · 2026

一句话：把 motion tracking 当基础训练任务，沿数据/模型/算力三轴做 scaling，用 FSQ 离散 token 统一五种输入模态。

SONIC 的出发点是：动捕数据天然提供逐帧稠密监督，不需要手工奖励也不需要对抗训练，这让 motion tracking 成为一个可 scale 的基础任务。三种编码器（robot / human / hybrid）各自处理不同来源的运动指令，输出共享 latent 后经 FSQ 量化为 universal token。双解码器分工：control decoder 输出关节目标，motion decoder 做辅助监督和跨编码器对齐。四项损失（PPO + 重建 + token 对齐 + 循环一致性）端到端联合优化。

关键结果：数据 4M → 1 亿帧、模型 1.2M → 42M 参数、算力 2K → 21K GPU-hr，三轴 scaling 全部未饱和。Tracking 成功率 98.7%（BeyondMimic 81.6%），MPJPE-L 23.2mm（BeyondMimic 39.1mm）。GR00T N1.5 VLA 直接预测 token 驱动 G1 完成 loco-manipulation，五项任务平均成功率 75%。FSQ token 比 SMPL 连续空间高 42 个百分点。真机 123 条运动成功率 99.2%。

核心 Insight：Universal token 就是人形机器人的"API 接口层"，VLA 只需预测 64 维 token，不用管底层 29 个关节怎么转。密集监督天然比对抗信号更适合 scaling，和自回归预测 next token 胜过 GAN 生成文本是同一个道理。

Humanoid-GPT Tsinghua & Galbot · CVPR 2026

一句话：把主流动捕数据集合成 20 亿帧语料，训练 300 个 PPO 专家后用 DAgger 蒸馏到一个因果 Transformer，首次验证 Transformer 在 humanoid tracking 上的 scaling 优势。

Humanoid-GPT 先用 Harmonic Motion Embedding（HME）把 2B 帧数据按运动的振幅/频率特征聚成约 300 个语义簇，每个簇训一个 PPO MLP 专家。然后将蒸馏重新定义为序列建模问题：用 DAgger 框架，让学生 Transformer 自己在环境中执行，每一步用对应簇的专家标注"正确动作"，通过 temporal parallel training 一次 forward pass 监督整个 H 帧窗口的输出。因果 attention 确保每个位置只看过去，部署时用 KV cache 做流式推理。

关键结果：80M 参数 Transformer 在 2B token 上训练，SR 92.58%，MPJPE 0.0735 rad，MPKPE 40.99mm，均为最优。同参数量 MLP 在大数据上饱和而 Transformer 不会。TensorRT + C++ 优化后推理延迟均值 0.39ms（<1.5ms 端到端），比 TWIST 快约 5 倍。真机上零样本跟踪舞蹈、格斗、搬箱子、踢足球等高动态动作。与 SONIC 对比视频显示更平滑的日常行为、更富表现力的舞蹈、更敏捷的高动态动作和更稳定的平衡保持。

核心 Insight：架构选型比数据工程更重要，同样 2M token 的小数据下 Transformer 比 MLP 高 6.37 个百分点。"先分后合"的专家蒸馏是一种算力友好的折中，把 RL 训练的成本控制在小 MLP 专家上，把 scaling 的红利留给 Transformer。HME 的 diversity-aware 采样机制解决了大数据集中常见动作淹没稀有动作的长尾问题。

五大演进维度

1. 训练信号：从手工到密集监督

纵观五代方案，训练信号的演化路径是：手工调参奖励（DeepMimic） → GAN 判别器奖励（AMP） → 逐帧动捕密集监督（SONIC） → 完全无任务奖励的自由探索（BFM-Zero）。每一次跳跃的本质都是让训练信号变得更 scalable。而信号的可扩展性，最终决定了整套方法的天花板。

回头看，结论和自然语言处理殊途同归：密集、明确、可自动获取的监督信号胜过一切精巧的间接设计。动捕数据之于 motion tracking，正如互联网文本之于 next token prediction：量大、天然稠密、不需要额外标注。

2. 表示空间：从连续关节到离散 token

表示空间经历了逐步抽象的过程：原始关节角度 → AMP 的隐式风格空间 → HOVER 的 CVAE 连续潜空间 → BFM-Zero 的 z 向量 / SONIC 的 FSQ 离散 token。

其中最关键的拐点出现在 SONIC 的 VLA 消融实验里：离散 FSQ token 的任务成功率比连续 SMPL 姿态空间高出 42 个百分点（68% vs 27%）。这组数据清楚地表明，全身动作的"API 接口层"正在从连续高维空间不可逆地走向离散低维 token。

3. 新任务成本：从重训到零样本

时代新任务成本
DeepMimic≈ 从零训练一个新策略
AMP/ASE重训策略，保留风格判别器
HOVER/ASAP重训底层 tracker + 重新蒸馏
BFM-Zero算一个 z 向量（毫秒级）
BeyondMimic写一个目标函数 + 推理时引导
SONIC换 encoder / 直接预测 token

4. Sim-to-Real：从纯仿真到稳定迁移

早期的 DeepMimic 和 AMP 只在仿真环境里验证，完全没有触及真实硬件。ASAP 首先迈出了这一步，用真机数据训练残差模型来弥补仿真与现实之间的动力学差距。BFM-Zero 随后在 off-policy 框架下用非对称训练 + 域随机化搞定了 sim-to-real 迁移，打破了"迁移到真机必须用 PPO"的惯性认知。到了 SONIC，真机上 123 条运动的成功率达到 99.2%，关节位置误差仅比仿真增加 3.4mm，sim-to-real 已经不再是瓶颈。

5. Scaling：从不存在到三轴未饱和

前三个阶段基本没有 scaling 叙事。阶段四开始出现初步验证：BFM-Zero 把模型从 40M 推到 680M 参数性能持续提升，Humanoid-GPT 发现 Transformer 架构在大数据上不饱和而 MLP 会。到了阶段五，SONIC 给出了目前最完整的三轴 scaling 曲线：数据、模型和算力三条线同时推大，没有任何一条出现饱和迹象。

值得注意的是，42M 参数和 1 亿帧数据放在大语言模型的视角下极其微小。如果 scaling 曲线继续保持这个趋势，推到数十亿参数和数百亿帧的规模，人形控制领域也许会迎来属于自己的"涌现时刻"。

数学范式对比

BFM-Zero：Forward-Backward 表示

BFM-Zero 的数学核心是同时学习两个映射，即 forward map $F(s,a,z) \in \mathbb{R}^d$ 和 backward map $B(s) \in \mathbb{R}^d$，让它们的内积近似策略 $\pi_z$ 的长期折扣状态访问分布：

$$M^{\pi_z}(\mathrm{d}s' \mid s, a) \simeq F(s, a, z)^\top B(s') \rho(\mathrm{d}s')$$
直觉：F 向量编码"从这里出发能到哪里"，B 向量编码"这个状态值多少"。内积就是预期折扣访问概率。任何线性奖励 $r(s) = \phi(s)^\top z$ 的最优策略由 z 自动给出。

SONIC：FSQ 量化 + 多编码器对齐

SONIC 的策略是让三种编码器（robot / human / hybrid）输出共享的 latent 向量，再经 FSQ 离散化为 universal token $z$。整个系统通过四项损失端到端联合优化：

$$\mathcal{L} = \mathcal{L}_{\text{ppo}} + \mathcal{L}_{\text{recon}} + \mathcal{L}_{\text{token}} + \mathcal{L}_{\text{cycle}}$$
PPO 强化学习损失 + 重建损失（三种编码器都能重建机器人运动）+ token 对齐损失（强制跨编码器一致）+ 循环一致性损失（human → robot → human 不走样）。

BeyondMimic：隐空间扩散 + Classifier Guidance

BeyondMimic 先用 VAE 将 (state, action) 对编码到平滑的隐空间 $z$，再在这个隐空间上训练一个扩散模型学习去噪过程：

$$p_\theta(z_0) = \int p(z_T) \prod_{t=1}^{T} p_\theta(z_{t-1} \mid z_t) \, \mathrm{d}z_{1:T}$$
推理时注入目标函数的梯度做 classifier guidance：$\tilde{\mu} = \mu_\theta + \sigma^2 \nabla_z \log p(g \mid z)$，不重训就能引导策略朝任意目标走。

Humanoid-GPT：因果 Transformer 自回归

Humanoid-GPT 的数学形式最为直白，把运动序列当作 token 序列，用因果 Transformer 做 next-action prediction：

$$a_t = \text{Transformer}(o_{t-H:t}, a_{t-H:t-1})$$
和 GPT 预测 next token 同一逻辑。观测-动作历史就是 context，KV cache 实现流式推理 <1.5ms。

结论与展望

当前格局

四个方案在不同维度上各有胜场，选择取决于具体需求：

  • SONIC 是综合实力最强的方案，跟踪精度最高、模态覆盖最广、是唯一完成 VLA 对接的选手，scaling 曲线也最完整。如果只能选一个方案来构建通用控制基座，它是当前的首选。
  • BFM-Zero 在理论优雅度上无出其右。无监督训练、可提示切换任务、少样本适应三者合一，且对动捕数据的需求最小。如果数据稀缺或需要快速适应未知场景，它是更合适的起点。
  • BeyondMimic 在单动作质量和测试时灵活性上领先。如果应用场景需要极致自然的全身动作，或者需要处理避障、导航等无法预先定义的隐式目标，它的 classifier guidance 机制是独一无二的。
  • Humanoid-GPT 贡献了最深刻的架构洞察：Transformer 在人形跟踪上的 scaling 优势是实证出来的，而非猜测。如果研究的核心问题是 scaling law 本身，它提供了目前最规范的实验方法论。

三个未解问题

1. 离散 token vs 连续表示，是否已成定论？

SONIC 的 +42pp 消融结果很有说服力，但目前只在一个 VLA 模型（GR00T N1.5）上得到了验证。另一方面，BFM-Zero 的连续 z 空间拥有线性奖励最优性的理论保证，在表达力上有天然优势。未来也许会出现"连续空间训练、离散 token 推理"的混合方案，兼取两家之长。

2. Scaling 的天花板在哪里？

42M 参数和 1 亿帧数据放在大语言模型的尺度下几乎可以忽略不计。如果 scaling 曲线延续当前趋势，推到数十亿参数和数百亿帧会发生什么？是否会出现某种形式的涌现能力？目前还没有人为人形控制做过 Chinchilla 式的最优 scaling 配比研究，这本身就是一个值得投入的方向。

3. 语言接口何时打通？

SONIC 已经通过 GR00T N1.5 实现了 VLA 对接，BFM-Zero 的 z 空间在理论上也可以映射自然语言指令。但"说一句话，机器人就做出对应的全身动作"这件事，端到端地还没有人做通。这很可能是下一个里程碑：language-conditioned whole-body control。

下一步猜想

  • 数据飞轮的闭合：SONIC 的 tracker 提升遥操稳定性 → 收集更好的 VLA 训练数据 → VLA 自主操作能力增强 → 部署产生更多数据。BFM-Zero 的 replay buffer 本身也构成一种飞轮。一旦这个循环闭合，数据增长将进入自增强轨道。
  • 跨形态泛化：BFM-Zero 的附录已经在 Booster T1 上用相同超参复现成功，SONIC 的 token 空间在设计上不绑定特定机型。统一多种人形平台的 BFM 是一个自然且明确的下一步。
  • 安全与能效的形式化：SONIC 坦承缺乏安全性和能效的形式化保证。在受控实验室里这不是问题，但当 BFM 真正进入日常部署场景时，这些会变成不可回避的硬约束。
  • Transformer 大统一：Humanoid-GPT 已经证明 Transformer 在 tracking 上 scaling 不饱和。一个自然的猜想是：把 SONIC 的 FSQ token + 多编码器架构嫁接到 Transformer backbone 上，将两条线目前最强的元素组合起来，可能释放更大的 scaling 潜力。

从"每个动作一个策略"到"所有动作一个 token 空间"，人形控制走了八年。自然语言处理从 Word2Vec 到 GPT-4 也差不多是这个时间跨度。如果类比成立，下一个八年，我们或许真的会看到"人形机器人的 GPT 时刻"。

Q&A

为什么对抗式方法（AMP/ASE/CALM）在大数据上会失败？

根本原因是判别器的训练信号随分布复杂度退化。AMP 的判别器要区分"真实动捕"和"策略生成"的状态转移分布。当动捕数据只有走路和跑步时，分布简单，判别器能给出有效信号。但当数据涵盖 8000+ 种动作时，真实分布变成极高维的多模态混合，判别器无法有效区分，信号退化为噪声。策略失去梯度方向后倾向于 mode collapse，只学会少数"安全"的动作。这和 NLP 里 GAN 无法生成高质量长文本是同一个道理：对抗训练信号的信息量不随数据量增长，而密集监督（逐帧跟踪目标或逐 token 预测目标）的信息量线性增长。

BFM-Zero 和 SONIC 的表示空间本质区别是什么？

BFM-Zero 的 z 向量定义了一个 任务空间：每个 z 对应一个线性奖励函数，策略 $\pi_z$ 自动是该奖励下的最优策略。z 空间的结构来自 FB 表示学习的理论保证（线性奖励最优性定理），是"自上而下"的。

SONIC 的 FSQ token 定义了一个 运动空间：每个 token 对应一段运动指令的离散编码。token 空间的结构来自动捕数据的统计分布，是"自下而上"的。

BFM-Zero 能回答"给定奖励函数，该怎么动"；SONIC 能回答"给定运动参考，怎么执行"。BFM-Zero 更 general（理论上覆盖所有线性奖励任务），SONIC 更 practical（直接对接 VLA）。

BeyondMimic 的扩散模型和 DreamZero 等 WAM 的扩散模型有什么区别？

关键区别在扩散的对象和目的。BeyondMimic 在 动作隐空间 上做扩散，目的是建模动作的多模态分布并支持 classifier guidance 组合技能。它的扩散只涉及策略动作，不预测图像。DreamZero 等 WAM 在 视频像素空间（或视频 token 空间）上做扩散，目的是建模世界的物理规律，动作是"嵌入"在视频预测过程中隐式学到的。BeyondMimic 的优势是推理更轻（只去噪动作隐空间，不生成图像），劣势是需要预先训练好一套 RL tracker 作为基座。

Humanoid-GPT 的 "MLP 饱和、Transformer 不饱和" 对其他方案意味着什么？

这个发现的影响深远。SONIC 目前用 MLP 做 tracker，在 42M 参数时 scaling 没饱和，但按 Humanoid-GPT 的经验，继续推大 MLP 迟早会撞墙。一个自然的猜想是：把 SONIC 的 FSQ token + 多编码器架构和 Transformer 结合，用 Transformer 做 control decoder 而非 MLP，可能释放更大的 scaling 潜力。这个方向还没人做，但逻辑上是 SONIC + Humanoid-GPT 的自然交集。

四个方案的实时性能差多少？部署时哪个最实际？

从推理速度看：Humanoid-GPT（<1.5ms，80M Transformer + TensorRT）≈ BFM-Zero（<1ms，31.9M MLP）> SONIC（TensorRT + CUDA Graph @50Hz，具体延迟未报告但够用）>> BeyondMimic（8 步扩散去噪，~25Hz）。部署最实际的是 SONIC：不仅推理够快，而且模态覆盖最广（VR/视频/文本/VLA 都能接），有完整的多线程部署栈（策略 50Hz、指令 500Hz、规划 10Hz）。BeyondMimic 的 25Hz 对动态任务来说偏慢，但扩散步数可以通过 DDIM 或 consistency distillation 压缩。

如果只关注 VLA + 全身控制这个方向，现在该跟哪条线？

跟 SONIC 的离散 token 路线，同时关注 BFM-Zero 的适应机制。理由：(1) SONIC 是唯一完成 VLA 对接的方案（GR00T N1.5 预测 token），且消融给出了定量证据（离散 vs 连续 +42pp）。(2) FSQ token 和 LLM 的 tokenization 是同一逻辑，VLA 本质上就是预测 token 序列，离散空间天然兼容。(3) BFM-Zero 的 prompt-level adaptation（不改参数、只优化 z 适应新场景）是 SONIC 目前缺失的能力，未来可能需要把两者结合，用 SONIC 的 token 空间做基座，用 BFM-Zero 式的在线优化做少样本适应。

这四个方案有没有可能融合成一个？

理论上可以设想一个"终极 BFM"：用 SONIC 的 密集监督 + FSQ token 做基础训练信号和表示空间，用 Humanoid-GPT 的 Transformer 架构 做 scaling backbone，用 BFM-Zero 的 FB 表示 做在线任务推理（换 z = 换任务），用 BeyondMimic 的 扩散 + classifier guidance 做复杂组合任务的规划层。这个四合一方案的核心挑战在于训练：off-policy FB 学习和 on-policy PPO tracking 的训练框架不兼容，需要一个新的统一训练算法。目前还没有人尝试。

和 NLP 的 scaling 故事相比，人形控制的 scaling 到了什么阶段？

大约在 GPT-2 到 GPT-3 之间的阶段。具体来说：(1) 基础训练任务已经找到（motion tracking ≈ next token prediction）。(2) Scaling 曲线已经画出来了，且没饱和（≈ GPT-2/3 验证了 scaling law）。(3) 还没有 Chinchilla 式的最优配比研究（数据/模型/算力怎么分配最高效）。(4) 涌现能力还没出现，42M 参数太小了，NLP 的涌现大约在 100B+ 才明显。(5) 语言接口还没打通（≈ NLP 有了 GPT-3 但还没有 ChatGPT）。如果 scaling 曲线继续保持，推到数十亿参数和数百亿帧，也许我们会看到人形控制的"涌现时刻"。
